# AI-Based-Business-Decision-Support-System
Retail Sales Analytics Dashboard using Power BI, ChatGPT, Zapier, Excel, Canva and GitHub.
AI-Based Business Decision Support System
Project Overview
This project analyzes retail sales data using Power BI and Artificial Intelligence techniques to support business decision-making.

Objectives
Analyze retail sales performance
Identify customer and regional trends
Generate AI-based business insights
Automate business processes using Zapier
Support data-driven decision making
Tools Used
Microsoft Excel
Power BI
ChatGPT
Zapier
Canva
GitHub
Dataset
Retail Sales Dataset containing:

Customer Information
Product Details
Category Data
Regional Sales
Order Information
Dashboard Features
Total Sales KPI
Total Profit KPI
Sales by Region
Sales by Category
Customer Segment Analysis
Geographic Sales Analysis
Zapier Automation
Workflow:

Google Form → Google Sheets → Zapier → Gmail

Whenever a new sales record is submitted through Google Forms, Zapier automatically sends an email notification.

Key Insights
West Region generated highest sales.
Technology category achieved maximum revenue.
Consumer segment contributed highest sales.
South Region presents growth opportunities.
Seasonal trends were identified.
Conclusion
The project demonstrates how AI, Business Intelligence, and Automation can improve business decision-making and operational efficiency.
